# gl-be3600-network-lab
OpenWrt GL-BE3600 HomeLab & IoT Network Lab for advanced networking experiments. This project documents a complete home/enterprise-style network architecture built on OpenWrt, including multiple isolated VLAN-like networks (Home, IoT, Guest, Lab), wireless bridge segmentation (br-lan, br-iot), and firewall-based isolation. It explores VPN setups (WireGuard, OpenVPN, site-to-site tunnels), AdGuard Home for DNS-level protection, and advanced routing scenarios such as failover internet, QoS tuning, and IPv6 deployment. The lab also includes cyber-security experimentation (Kali Linux, scanning, IDS/IPS), container and service hosting (NAS, Samba, monitoring tools), and automation integrations (Home Assistant, Prometheus, Grafana). Designed as a practical learning environment to simulate real-world enterprise networking and DevOps-style infrastructure on a home router.
