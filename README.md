# openwrt-gl-be3600-iot-network-lab
OpenWrt GL-BE3600 home network lab for experimenting with VLAN-style segmentation (Home, IoT, Guest, Lab), VPNs (WireGuard/OpenVPN, site-to-site), AdGuard DNS filtering, QoS, IPv6, failover internet, and advanced routing. Focused on real-world networking, security, and home infrastructure automation.
